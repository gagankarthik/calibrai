## What is TalentBridge?

TalentBridge is the AI-powered talent acquisition platform built for the era of skills-based hiring. Unlike LinkedIn — which is optimized for virality and networking — or Workday — which is optimized for enterprise compliance — TalentBridge is optimized for a single outcome: the right candidate in the right role, faster and fairer than any platform that came before it.

Every match on TalentBridge is generated by a semantic AI engine that evaluates 47 candidate signals against 130+ job dimensions. Companies receive a pre-ranked, bias-reduced shortlist within hours, not weeks. Candidates receive transparent, real-time status updates at every stage, AI-generated explanations of why they matched, and salary intelligence so they never leave money on the table. Zero ghosting. Zero guesswork. Just signal.

## Key Features

### AI Match Engine

TalentBridge does not do keyword search. Our semantic matching engine converts candidate profiles and job descriptions into high-dimensional embeddings, then scores every candidate against every job across 47 weighted signals: technical skill depth, experience trajectory, cultural alignment indicators, salary fit, work-mode preferences, and more. Each match generates an explainable score (0–100) with human-readable reasons — so hiring teams understand *why* a candidate ranked first, and candidates understand what made them a fit.

---

### For Companies

- **Pipeline Kanban Board** — Drag-and-drop candidate management from New through Hired, with per-column candidate counts, stage timestamps, and bulk actions.
- **Bias Detection** — Real-time alerts when demographic patterns in your pipeline diverge from your stated diversity targets. Built on anonymized profile evaluation in early stages.
- **Salary Intelligence** — Market salary benchmarks by role, location, and experience level. Know exactly what a competitive offer looks like before you make it.
- **Skills-Based Assessment Verification** — Candidates complete proctored, role-specific technical assessments. Verified skill scores appear on every profile card.
- **Analytics Dashboard** — Hiring funnel conversion rates, sourcing channel ROI, time-to-hire trends, cost-per-hire tracking, offer accept rate vs. industry, and diversity metrics — all in one place.
- **Team Collaboration & Scorecards** — Structured interview scorecards, internal notes, star ratings, and @-mention notifications keep your entire hiring team aligned.
- **ATS Integrations** — Native integrations with Greenhouse, Lever, Ashby, and Workday. Data flows both ways — no double entry.
- **Predictive Retention Scoring** — Our model predicts 1-year retention probability for every candidate at offer stage, trained on 87K+ successful placements.

---

### For Job Seekers

- **Smart Job Match Feed** — Every job listing includes an AI match score and 3 plain-language reasons why you matched, so you apply with confidence.
- **Application Tracker (Zero Ghosting)** — Every application you submit shows its current stage in real time. Companies on TalentBridge are contractually required to update statuses.
- **Skills Verification Lab** — Complete proctored assessments for React, TypeScript, Python, System Design, SQL, and 40+ other skills. Verified badges appear on your public profile.
- **Salary Benchmarking** — See the P25, median, and P75 compensation for your exact role, city, and experience level. Know your number before you negotiate.
- **Career Path Intelligence** — Data-driven projections of where professionals with your profile go next: Staff Engineer, Engineering Manager, Principal, CTO — with percentage breakdowns from 87K real career paths.
- **Profile Strength Scoring** — A real-time completeness score (0–100) with specific, actionable recommendations. Every 10-point increase in profile strength yields measurably more matches.

## Getting Started

### Prerequisites

```bash
node >= 18.17.0
npm  >= 9.0.0
```

### Install & Run

```bash
# Clone the repository
git clone https://github.com/talentbridge/talentbridge.git
cd talentbridge

# Install dependencies
npm install

# Start development server
npm run dev
# → http://localhost:3000
```

### Production Build

```bash
npm run build     # Type-check and build optimized output
npm start         # Serve production build on port 3000
npm run lint      # ESLint check
```

## Environment Variables

Create a `.env.local` file in the project root. The following variables are required for full production functionality:

```bash
# App
NEXT_PUBLIC_APP_URL=https://talentbridge.io
NEXT_PUBLIC_APP_ENV=production

# Database (PostgreSQL via Supabase or PlanetScale)
DATABASE_URL=postgresql://user:password@host:5432/talentbridge
DIRECT_URL=postgresql://user:password@host:5432/talentbridge

# Authentication (NextAuth.js)
NEXTAUTH_URL=https://talentbridge.io
NEXTAUTH_SECRET=your-nextauth-secret-min-32-chars

# OAuth Providers
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret
LINKEDIN_CLIENT_ID=your-linkedin-client-id
LINKEDIN_CLIENT_SECRET=your-linkedin-client-secret

# Stripe (billing)
STRIPE_SECRET_KEY=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_live_...

# Stripe Price IDs
STRIPE_PRICE_STARTER_MONTHLY=price_...
STRIPE_PRICE_STARTER_ANNUAL=price_...
STRIPE_PRICE_GROWTH_MONTHLY=price_...
STRIPE_PRICE_GROWTH_ANNUAL=price_...
STRIPE_PRICE_ENTERPRISE_MONTHLY=price_...

# Email (Resend or Postmark)
RESEND_API_KEY=re_...
EMAIL_FROM=noreply@talentbridge.io

# AI / Embeddings (OpenAI)
OPENAI_API_KEY=sk-...
OPENAI_EMBEDDING_MODEL=text-embedding-3-large

# File Storage (Cloudflare R2 or AWS S3)
S3_BUCKET=talentbridge-uploads
S3_REGION=us-east-1
S3_ACCESS_KEY_ID=...
S3_SECRET_ACCESS_KEY=...

# Analytics (Optional)
NEXT_PUBLIC_POSTHOG_KEY=phc_...
NEXT_PUBLIC_POSTHOG_HOST=https://app.posthog.com
```

## Competitive Advantage

**vs. LinkedIn Recruiter** — LinkedIn is an ad network masquerading as a talent platform. TalentBridge has no advertising revenue motive, so every recommendation is optimized purely for match quality, not paid placement or engagement.

**vs. Greenhouse** — Greenhouse is an applicant tracking system that helps companies manage workflows. TalentBridge is a match engine first: we surface the right candidates before they even apply, then track them through a purpose-built pipeline.

**vs. Lever** — Lever's strength is CRM-style relationship nurturing for large talent teams. TalentBridge wins on speed and AI accuracy for companies that need to hire now, not build a multi-year pipeline.

**vs. Workday Recruiting** — Workday is a compliance-first enterprise system with recruiting bolted on. TalentBridge is recruiting-native, with 10x the AI surface area and a UI designed for recruiters, not HR administrators.

**vs. Ashby** — Ashby is a modern ATS with excellent analytics. TalentBridge goes further: we generate candidates, not just track them. Our AI match engine reduces sourcing effort by 70% before an ATS workflow even begins.
